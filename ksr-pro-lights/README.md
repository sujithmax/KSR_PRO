# KSR PRO LIGHTS Website

Static multi-page website (HTML, CSS, JavaScript) for KSR PRO LIGHTS, Hyderabad.

## Structure
All files sit in the repository root: `index.html`, `about.html`, `equipment.html`, `services.html`, `gallery.html`, `contact.html`, `styles.css`, `script.js`, plus images (`logo.jpg`, `founder1.jpg`, `founder2.jpg`).

## Publish on GitHub Pages
1. Upload all files to the repository root (not inside a sub-folder).
2. Settings, Pages, Source: "Deploy from a branch", Branch: `main`, Folder: `/ (root)`.

## Notes
- Contact and feedback forms open WhatsApp with a prefilled message; the visitor presses Send.
- Gallery and equipment images are sample photos from Unsplash. Replace them with your own photos before launch.
- A Content Security Policy is set in each page. If you add new external scripts, fonts or images, allow their domain in the policy.
